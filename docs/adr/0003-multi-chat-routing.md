# ADR 0003: маршрутизация нескольких чатов

**Статус:** принято.

Один session-wide pump принимает уведомления независимо от активного диалога и маршрутизирует их по положительному числовому MAX `chatId`. Личным считается только `senderData.chatType === "user"`; group/channel/bot не создают диалоги. Валидный личный отправитель, которого ещё нет в состоянии, создаёт неактивный диалог; безопасный `chatName` становится label, иначе используется `Чат {chatId}`. Входящее сообщение увеличивает unread. Открытие диалога сбрасывает unread.

Исходящий чат сначала разрешается через `CheckAccount` из поддерживаемого номера России/Беларуси. Возвращённый numeric `chatId` является общей identity для исходящих и входящих событий; совместимый send-only формат `phoneNumber@c.us` намеренно не используется.

Дубликаты определяются составным ключом `chatId:idMessage`, чтобы одинаковые provider ID в разных чатах не конфликтовали. Применение новых реквизитов создаёт новую логическую сессию и полностью сбрасывает историю, диалоги и dedupe-набор, исключая смешивание аккаунтов.
