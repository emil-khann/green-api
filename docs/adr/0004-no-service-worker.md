# ADR 0004: не добавлять service worker и offline cache

**Статус:** принято.

Реквизиты и история живут только в памяти. Закэшированная оболочка без них не даёт полноценного offline-сценария, но добавляет риски устаревших assets, сложных обновлений и перехвата чувствительных запросов. Service worker не должен кэшировать или перехватывать URL с GREEN-API token, runtime-ответы API либо сообщения. Cache Storage, IndexedDB и скрытая очередь отправки не используются.

Offline честно приостанавливает polling и блокирует отправку; после online pump запускается заново. Решение можно пересмотреть только после появления backend-аутентификации, безопасного постоянного хранилища и явно спроектированной модели синхронизации/конфликтов.
