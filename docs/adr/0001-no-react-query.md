# ADR 0001: не использовать TanStack Query

**Статус:** принято.

Notification API — потребляемая FIFO-очередь с обязательным ack, а не кэшируемое server state. Автоматические refetch, retry при focus/reconnect и конкурентные запросы могут нарушить порядок `receive → delete`; полезного общего кэша в текущем приложении нет. Поэтому цикл реализован явно через application port и один pump.

Решение пересматривается, если появится независимое read-only server state (например, профиль или каталог), для которого дедупликация запросов и cache invalidation действительно полезны. Очередь уведомлений даже тогда останется вне React Query.
